個人用連携ツール

プライバシーポリシー

本ツールは所有者本人の個人利用を対象とします。Google 連携は準備中であり、以下の取扱方針に適合することを確認してから利用を開始します。

取得と利用

本人確認のための Google アカウント情報、依頼に必要なメールの送信元・受信日時・件名・本文、指定カレンダーの予定・共有設定を取得します。メール情報の確認、予定の参照・登録・変更、および接続先と共有範囲の確認に利用します。Google メールの送信・変更・削除は行いません。

外部サービスと共有

依頼の処理に必要な情報を、外部 AI API（OpenAI、TypeSafe）へ送信する場合があります。送信データをモデルの学習に利用しない条件と設定を確認した接続先だけを使用します。結果は本人が指定・許可した共有先へ反映・通知する場合があります。広告配信やデータ販売には利用しません。

保存と削除

認証情報と取得データは非公開で管理する方針です。開発用の原文・ログ・評価用コピーとその派生データは、出典を本ツールで最初に保存した時点から最大30日で削除します。予定登録等の確定結果と重複操作を防ぐための必要最小限の記録は、本人の削除指示まで保持します。外部サービス側の保持は各サービスの条件に従い、本ツール側の削除で外部側の消去完了を保証するものではありません。

利用の停止と連絡先

Google アカウントの接続管理からアクセス権を取り消せます。取消しによって取得済みデータや作成済み予定が自動削除されるわけではありません。保存データの削除や本方針に関する連絡は、下記のお問い合わせ先で受け付けます。

Google データの利用・他サービスへの転送には、Google API Services User Data Policy（Limited Use 要件を含む）を適用します。
